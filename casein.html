Casein Metamaterials: Programmable Bio-Actuated Proteins for 4D Fabrication

Aditya Retnanto
Individual final project · HTGAA (How to Grow Almost Anything) 2026 · Proposal

HTGAA project page

About

Desktop fabrication relies mostly on PLA and ABS, which are static and slow to degrade. This project asks whether motion can be designed into the material itself, all the way down at the level of protein sequence. The idea is to program casein, the main protein in milk, so that thin films made from it bend, twist, or bloom in a designed way when humidity changes. The result would be biodegradable, shape-changing material for 4D fabrication.

Concept

Shape-changing films usually work like a bilayer: one side swells with moisture while the other stays stiff, so the film curls. Here, both behaviors would be designed into a single protein:

  • Active side: casein already attracts water. Adding repeating motifs inspired by resilin, the elastic protein in insect wings, is meant to strengthen this response.
  • Passive side: motifs inspired by keratin, the protein in hair and nails, add crosslinking points that are meant to stiffen the opposing region.
  • The mismatch in swelling between the two sides should turn a change in humidity into a designed curvature.

Computational Design

  • Designed variants of β-casein, from the unmodified protein to a resilin + keratin chimera.
  • Ran hydrophobicity (Kyte-Doolittle) and water-binding analyses. These estimate about 36% more water binding for the resilin variant and about 48% more for the chimera, relative to native casein.
  • Predicted structures with ESMFold, and built a small "codon-jitter" tool that varies synonymous codons so repeated segments can be synthesized as DNA.

Status & Next Steps

The project is currently a proposal backed by computational analysis. The predicted gains have not yet been confirmed by physical experiments. Next steps:

  • Produce the designed proteins, cast films from them, and compare their humidity response with plain casein films.
  • Build a library of validated "actuation primitives" (bend, twist, bloom) that designers can combine.
  • Integrate these primitives with CAD tools, so that motion can be specified in the design environment the way geometry is today.

The project connects my interests in fabrication and shape-changing interfaces with bio-based materials.
